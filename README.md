# Sorteou — Apresentação do sistema

Apresentação web dos 16 módulos do Sorteou, com interfaces recriadas em HTML e dados inteiramente fictícios.

## Acessar

[Ver apresentação](https://rodrigobs4.github.io/sorteou-apresentacao/)

## Usar

- Selecione um módulo no menu.
- Clique em **Apresentar** para tela cheia e navegue com **← →**.
- Clique na interface para ampliar.
- Use **Esc** para sair.

## Executar localmente

Abra `index.html` no navegador ou use um servidor estático:

```sh
python3 -m http.server 4173
```

A apresentação usa HTML, CSS e JavaScript, sem instalação de dependências. Não se conecta ao sistema real, não contém credenciais e não utiliza dados de clientes.
